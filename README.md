# AI Prompt Builder

AI Prompt Builder is an early-stage MVP that turns rough natural-language ideas into structured prompts.

## MVP
- Prompt builder workspace
- Goal / audience / tone controls
- Reusable prompt structure
- Copy-to-clipboard
- Responsive dark UI
- Claude API integration ready for the next phase

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Roadmap
1. Claude API integration
2. Prompt history and saved prompts
3. User authentication
4. Prompt templates
5. Prompt evaluation / scoring
6. Team workspaces
7. Usage analytics

## Positioning
AI Prompt Builder helps developers, students, creators and early-stage teams convert vague instructions into clear, reusable prompts for modern LLM workflows.
